# GazeBloom — نمونه اولیه یادآور دسکتاپ

**این نرم‌افزار یادآور استراحت است؛ نه ابزار پزشکی، اندازه‌گیری تطابق چشم یا درمان.**

## راه‌اندازی
```bash
git clone https://github.com/ehsanrs2/GazeBloom.git
cd GazeBloom
# در صورت نیاز در اوبونتو/دبیان:
sudo apt install python3-tk
python3 -m gazebloom
python3 -m gazebloom --interval-min 10
# فقط با رضایت خودتان؛ ثبت حداقلی و محلی رویدادها:
python3 -m gazebloom --log ~/gazebloom-events.jsonl
```

در لینوکس اگر `notify-send` موجود باشد، اعلان سیستم به‌صورت best-effort نمایش داده می‌شود. در غیر این صورت یادآور در پنجره برنامه است. اجرای پس‌زمینه پس از بستن برنامه وجود ندارد.

- تایمر از `time.monotonic()` استفاده می‌کند. زمان‌بندی پیشنهادی ۲۰ دقیقه و مدت استراحت ۲۰ ثانیه است؛ هیچ ادعای درمانی یا برتری علمیِ قطعیِ این زمان‌بندی وجود ندارد.
- کاربر شروع، مکث/ادامه، شروع وقفه، Snooze پنج دقیقه، رد اعلان، توقف زودهنگام و توقف کامل را کنترل می‌کند.
- بعد از ۲۰ ثانیه، تنها با کلیک `Confirm break` رویداد `break_completed` ثبت می‌شود. **انجام نگاه واقعی به دور از طریق چشم پایش نمی‌شود**.
- تغییر غیرعادی اختلاف ساعت دیواری و monotonic باعث توقف محافظه‌کارانه و نیاز به ادامه دستی می‌شود؛ این نشانه الزاماً به معنی تعلیق سیستم نیست.
- هنوز تشخیص idle، زمان واقعی نگاه به مانیتور، تشخیص fullscreen، ترجمه فارسی و یکسان‌سازی اعلان سیستم‌عامل‌ها وجود ندارد.
- بدون `--log` اطلاعات کاربر روی دیسک ذخیره نمی‌شود. در حالت opt-in فقط رویداد حداقلی، زمان UTC و شناسه تصادفی جلسه در JSONL محلی نوشته می‌شود. هیچ دوربین، حساب، تصویر صفحه، پایش موس/کیبورد یا تله‌متری وجود ندارد.
- **تمرین ChromaBlur در این برنامه نیست**؛ نمایشگر تخت جای نگاه به شیء فیزیکی دور را نمی‌گیرد.
