# uv / Python interpreter policy (GazeBloom)

GazeBloom uses **uv** for dependency resolution and virtual environment management.

- Project metadata and direct dependencies: `pyproject.toml`
- Reproducible lockfile: `uv.lock` (generated by `uv lock`; committed after bootstrap)
- Suggested runtime: Python 3.12 (`.python-version`); Ubuntu 24.04 uses `/usr/bin/python3` / 3.12.
- Desktop GUI is Tkinter (standard library + native extension). **uv cannot turn a Python build without `_tkinter` into a Tk-enabled build just by installing Python packages.**

## Ubuntu 24.04 with Linuxbrew Python

Your terminal's `python3` may resolve to Linuxbrew 3.14 even though `python3-tk` belongs to system Python 3.12. Confirm:

```bash
which python3
python3 --version
/usr/bin/python3 --version
/usr/bin/python3 -c 'import _tkinter, tkinter; print("Tk OK")'
```

Use the Ubuntu interpreter for the desktop GUI, but let uv own the **virtual environment and packages**:

```bash
sudo apt install python3-tk
cd /path/to/GazeBloom
# If .venv was previously built from an incompatible interpreter,
# remove ONLY this repo's environment after verifying you are in its root:
rm -rf .venv
uv sync --python /usr/bin/python3 --no-managed-python --locked
uv run --python /usr/bin/python3 --no-managed-python --locked python -m gazebloom --interval-min 1
```

Optionally, use `uv run --python /usr/bin/python3 --no-managed-python --locked gazebloom --interval-min 1` via the project script entry point.

**Do not** use `sudo uv`, `uv pip install --system`, or install Python project dependencies using apt/pip globally.

## Research dependencies

The reminder app has no Python third-party *runtime* dependencies; scientific packages are an optional extra:

```bash
uv sync --python /usr/bin/python3 --no-managed-python --locked --extra research
uv run --python /usr/bin/python3 --no-managed-python --locked --extra research \
  python experiments/gaussian_lca_v0/test_model.py
```

Run offline tests with `uv run --locked --extra research python -m unittest discover -s tests -v` (after the appropriate interpreter/environment has been selected).

## Platform notes

Tkinter uses the exact Python executable's native `_tkinter` extension. Another Python interpreter's Tk package is not interchangeable. For other Linux distributions, install their matching Python/Tk system package or use an interpreter which includes Tk. On CI, headless numerical tests can use uv-managed Python, while the dedicated Ubuntu integration test installs OS Python/Tk and verifies the uv environment preserves it.

## Lockfile policy

When changing dependencies, run `uv add --optional research PACKAGE` or edit `pyproject.toml` and run `uv lock`; commit both manifest and lockfile. CI must use `uv sync --locked`, and failures must not silently rewrite the lock. A one-off migration bootstrap may run `uv lock` in CI to generate the first lockfile; subsequent runs must validate the tracked lock.
