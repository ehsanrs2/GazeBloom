# R16 — ممیزی توقف در رابط خنثی، بدون داوطلب

**دامنه:** `R16_NEUTRAL_ONLY_STOP_DISPATCH`. این مرحله نمایشگر پژوهشی H1 یا آزمایش انسان نیست. هیچ تصویر R12، ویدئو، دوربین، ثبت شرکت‌کننده یا جمع‌آوری داده شخصی وجود ندارد.

## هدف و تعریف اندازه‌گیری

R14 صرفاً از ساعت مجازی استفاده می‌کرد. R16 در یک رابط Tk با نوشته خنثی، فاصله زمانی بین **ورود به تابع STOP** و **پایان اجرای `update_idletasks()` پس از تغییر Label** را با `time.perf_counter` ثبت می‌کند.

- این فاصله، latency ورود رویداد فیزیکی کلید از OS نیست؛ زمان واکنش انسان نیست.
- خروجی `update_idletasks` نشان‌دهنده پایان دستورهای Tk روی همان فرایند است، نه زمان scan-out، تغییر واقعی نور مانیتور یا ناپدید شدن تصویر از شبکیه.
- کلید Esc، دکمه STOP و بستن پنجره در حالت اپراتوری به همان latch خاتمه‌دهنده متصل‌اند؛ اجرا دوباره مجاز نیست.
- در صورت خطای callback، حالت STOPPED باقی می‌ماند ولی زمان موفق گزارش نمی‌شود. چنین خطایی به معنی ایمنی نیست و باید مستقل بررسی شود.
- مقادیر ms صرفاً توصیفی‌اند، بدون هیچ آستانه PASS فیزیولوژیک یا تضمین safety.

## اجرا

آزمون خالص، بدون ایجاد پنجره:

```bash
uv run --locked python -m unittest discover -s experiments/r16_neutral_stop_audit -p 'test_*.py' -v
```

نمایش مصنوعی Tk با فراخوانی مستقیم STOP (بدون فشردن دکمه و بدون تصویر):

```bash
python experiments/r16_neutral_stop_audit/stop_audit.py --ci-smoke --samples 10 --out /tmp/gazebloom-r16-ci.json
```

بازبینی صرفاً اپراتوری رابط خنثی، با دکمه، Esc یا بستن پنجره:

```bash
python experiments/r16_neutral_stop_audit/stop_audit.py --operator-demo
```

اجرای محلی نیازمند Python دارای `tkinter` و محیط گرافیکی است. `--out` فایل موجود را بازنویسی نمی‌کند. نمونه مصنوعی CI در Xvfb اجرا می‌شود؛ شبیه‌ساز نمایشگر واقعی نیست.

## معیار پذیرش مهندسی

1. توقف از وضعیت آماده و نمایش خنثی پایانی است و هیچ restart ندارد.
2. فراخوانی تکراری STOP دوباره callback اجرا نمی‌کند.
3. خطای callback و زمان نامعتبر به عنوان اندازه‌گیری موفق ثبت نمی‌شوند.
4. CI در هر دو نسخه Python آزمون خالص را اجرا کند و Ubuntu/Xvfb فقط رابط **خنثی** را آزمایش کند.
5. خروجی‌های CI باید `human_participants=0`، `actual_pngs_opened=0` و `human_exposure_authorized=false` داشته باشند.

**گیت همچنان باز:** طراحی و آزمون مستقل خاموش‌سازی تصویری واقعی، اندازه‌گیری فیزیکی نمایشگر، موافقت اخلاقی/رضایت/حریم خصوصی R15، و تأیید جداگانه برای H1. این مرحله به هیچ‌یک مجوز نمی‌دهد.
