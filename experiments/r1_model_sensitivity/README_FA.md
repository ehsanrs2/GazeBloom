# GazeBloom / Track B / R1 — اعتبارسنجی مدل و تحلیل حساسیت

**وضعیت: اجرای محاسباتی، بدون آزمایش روی چشم انسان.**

## انگیزه
پس از ادغام مسیر اپلیکیشن تا PR #4، تمرکز پروژه به پژوهش محرک‌های تصویری منتقل شده است. چون به اتورفرکتومتر، فوتورفرکتومتر یا ابزار اندازه‌گیری تطابق دسترسی نداریم، **تغییر واقعی تطابق یا فعالیت ماهیچه مژگانی را با این پروژه نمی‌توان اثبات کرد**. هدف R1 صرفاً تعیین اعتبار و حدود قابل‌اتکای *مدل محاسباتی فعلی* است؛ نه ساخت تمرین درمانی.

مقاله پایه: Cholewiak, Love & Banks (2018), [Creating correct blur and its effect on accommodation](https://pmc.ncbi.nlm.nih.gov/articles/PMC6126933/). مدل موجود GazeBloom بازتولید کد یا پروتکل اپتیکی مقاله نیست.

## سؤال‌های پژوهش
- **B1:** آیا PSFهای عددی در مدل موجود نرمال، متقارن، غیرمنفی و نسبت به افزایش تفکیک شبکه FFT تقریباً پایدار هستند؟
- **B2:** خطای بازسازی مدل برای دو علامت فرضی defocus و پارامترهای متنوع نمایشگر و مردمک چقدر است؟ چه نواحی‌ای ضعیف یا ناپایدارند؟
- **تعبیر غیرمجاز:** حتی PSF fit عالی نشان نمی‌دهد که یک چشم واقعی فوکوس خود را تغییر داده یا کاربر خستگی کمتری حس کرده است.

## پیاده‌سازی
`sweep.py` مدل `experiments/waveoptics_q1_v1/waveoptics_validation.py` را بدون دستکاری مستقیم فراخوانی می‌کند. برای هر نقطه شبکه:
1. PSF پایه در فاصله فیزیکی ثابت نمایشگر و طول‌موج نماینده R/G/B محاسبه می‌شود.
2. برای دو تغییر جبری `+ΔD` و `−ΔD` یک PSF هدف محاسبه می‌شود. این‌ها **برچسب‌های جبری** هستند، نه پیش‌بینی قطعی جهت پاسخ انسان.
3. سه وضعیت بدون تاریِ اضافه، تاری Gaussian یکسان برای RGB (یک پارامتر) و Gaussian جداگانه کانال‌ها (سه پارامتر) با معیار مشترک مقایسه می‌شوند.
4. خطاهای مطلق و درصد تفاوت خطای مدلی ثبت می‌شود.
5. برای مورد اول، PSF شبکه FFT ۳۲۰ و ۴۸۰ در وضعیت پایه مقایسه می‌شود؛ این *بررسی همگرایی توصیفی* است و هیچ آستانه تجربی را اثبات نمی‌کند.

### معیار کمّی اصلی در این مرحله

برای PSF مدل در هر کانال (c)، `P_c` پیش‌بینی و `T_c` هدف:

`normalized_joint_L2 = sqrt( sum_c ||P_c − T_c||₂² / sum_c ||T_c||₂² )`

هرچه کوچک‌تر باشد برازش PSF مدلی بهتر است، **اما ارتباط مستقیمی با مقدار تطابق چشم ندارد**. بهبود درصدی `100 × (1 − error_RGB / error_shared)` گزارش می‌شود. مدل RGB سه درجه آزادی دارد و مدل مشترک یکی؛ بنابراین **بهبود، به‌تنهایی کشف علمی یا گواه اثر محرک نیست**.

### محدوده پارامترها

| حالت | فاصله (m) | گام پیکسل (mm) | مردمک (mm) | ΔD (قدر مطلق) | نقاط |
|---|---|---|---|---|---:|
| `smoke` | 0.60 | 0.27 | 3، 4 | 0.45 | ۲ |
| `pilot` | 0.50، 0.80 | 0.24، 0.31 | 3، 5 | 0.30، 0.60 | ۱۶ |
| `extended` | 0.50، 0.60، 0.80 | 0.20، 0.27، 0.34 | 2.5، 4، 5.5 | 0.20، 0.45، 0.75 | ۸۱ |

برای هر نقطه دو جهت محاسبه می‌شود. این نمونه‌برداری طراحی اولیه است؛ مقادیر از اندازه‌گیری مانیتور یا چشم خاصی استخراج نشده‌اند.

## اجرا با uv

```bash
uv sync --python /usr/bin/python3 --no-managed-python --locked --extra research

uv run --python /usr/bin/python3 --no-managed-python --locked --extra research \
  python -m unittest discover -s experiments/r1_model_sensitivity -v

uv run --python /usr/bin/python3 --no-managed-python --locked --extra research \
  python experiments/r1_model_sensitivity/sweep.py \
  --preset smoke --out outputs/reproduction/r1_smoke

uv run --python /usr/bin/python3 --no-managed-python --locked --extra research \
  python experiments/r1_model_sensitivity/sweep.py \
  --preset pilot --out outputs/reproduction/r1_pilot
```

حالت `extended` صرفاً برای گسترش بعد از بررسی پایلوت موجود است. اجرای آزمایش روی GPU یا داده انسانی در این PR وجود ندارد.

## فایل‌های تولیدی
- `sweep.csv` — برای هر نقطه و جهت: خطاهای پایه، شاهد مشترک، سه کانال، sigmaهای بهینه، بهبود مدلی.
- `summary.json` — توزیع خطاها، تعداد موارد برازش بهتر، وضعیت فرضیه‌ها و فهرست عوامل بررسی‌نشده.
- `manifest.json` — محورهای واقعی sweep، نسخه مفسر و NumPy و SHA-256 مدل پایه/runner.
- `fit_summary.png` — نمایش نموداری خطاهای *محاسباتی*.

خروجی بازتولید در `outputs/reproduction/` قرار می‌گیرد و وارد GitHub نمی‌شود. آزمایش در CI با `smoke` انجام می‌شود؛ برای نتیجه‌گیری درباره همه محورهای `pilot` باید اجرای کامل همان preset مشاهده و ممیزی شود.

## محدودیت‌ها و معیار تصمیم
- طول موج‌ها، طیف واقعی RGB نیستند؛ gamma، طیف نمایشگر، رنگ‌سنجی، clipping و PSF فردی مدل نشده‌اند.
- PSF متقارن و قطر مردمک ثابت فرض شده؛ مدل از ابیراهی بالاتر و پاسخ تطابق بازخوردی صرف‌نظر می‌کند.
- مدل تنها **تاری افزایشی Gaussian غیرمنفی** را بهینه می‌کند؛ این خانواده نمی‌تواند مولفه‌های ازبین‌رفته در اپتیک پایه را بازسازی کند.
- B1 فقط درباره سازگاری محاسباتی حکم می‌دهد و در این مرحله آستانه «موفقیت علمی» برای برازش PSF تعیین نمی‌کند.
- اگر همگرایی عددی ضعیف باشد یا خطای باقیمانده بزرگ باشد، توسعه مدل بهینه‌سازی نمایشگر از تولید محرک‌های بیشتر اولویت بالاتری خواهد داشت.
- برای ارتقا به تمرین عمومی یا ادعای درمانی، شواهد آزمایش‌های انسانی معتبر و مرتبط لازم است. آزمون سلیقه یا وضوح تصویر جایگزین سنجش تطابق نیست.
